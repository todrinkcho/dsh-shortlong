# 短考 / 长考（`@todrink/dsh-shortlong`）

一个**会话级**的工作模式开关，回答一个问题：*用户现在在不在旁边？*

- **短考（short）**——人在旁边，随时能答话。该问就问，一次问完；能直接动手就别先讲方案；交付先给结论。
- **长考（long）**——人已经离开，可能几小时不回来。不问选择题、不停下来等；缺信息按最合理假设往下做，把替用户做的决定记下来，回来一次性汇报。

这不是一个 UI 皮肤，而是把「用户在场与否」变成一条**可切换、可持久、可审计**的契约：agent 拿到的 prompt 段、可用的工具、会话里留下的标记，三者永远一致。

## 装

```bash
# GUI：侧栏 插件 → 添加插件 → @todrink/dsh-shortlong
# 或让 agent 调 plugin_manager → install_bundle → @todrink/dsh-shortlong
```

适用 DSH `>= 0.2.2-rc.5`，装完重启。全平台（纯 host + web client，没有平台相关代码）。

## 用

在会话里敲斜杠命令：

| 命令 | 效果 |
|---|---|
| `/mode` | 在短考/长考之间切换（不带参数即切换） |
| `/mode short` | 切到短考 |
| `/mode long` | 切到长考 |
| `/mode status` | 只报当前模式，不切换，也不留标记 |

输入框里的小胶囊会跟着变。**只有真正切换才会留下 `>_ mode · 短考/长考` 这一行**——单纯打开会话不会。

## 设计要点

- **状态来自会话日志，不是插件内存**：`/mode` 命令的结算文本是唯一真相，插件把它折成 `{ mode }` 投影。所以模式能扛住 host 重启、页面刷新、会话恢复和 fork（早期版本在 host 重启后会退回短考）。
- **长考时禁掉 `ask_user_question`**：那个工具会弹一张没人会点的选择题卡片。禁用它，人才不会被卡在"选择题永远没人答"的死等里。
- **唯一写入者是 `/mode`**：其它路径只读。所以界面上的标记和真正生效的策略不会打架。

## 已知限制

- 两段 prompt 文本目前是中文的；要在英文环境用得自己改 `SHORT_TEXT` / `LONG_TEXT`。
- 长考的约束（不许对外不可逆操作、删前先备份）是写进 prompt 的**行为约定**，不是沙箱强制；真正的权限还得靠 DSH 自己的审批与沙箱。
- 模式是按会话存的，不跨会话继承。
